# Main Idea: Angry Birds Clone

## Description
A simple clone of Angry Birds which includes elements like gravity, collisions, enemies, launching systems, etc.

## Purpose
This is meant to be a project to show what I can do in coding as I'm not the best coder, so this would be good to create, especially for a potential resume down the line.

## Target User
This is meant for people who like Angry Birds and myself

## Planned Features
Gravity & Collisions
Multiple Levels
Player and Enemies

## Program Structure
Main Class
Enemy Class
Gravity & Colissions Class
Player Class
Levels Class

## Challenges
Implementing gravity and colissions will be the most difficult part of the project.

## Phase 3 Report
While there are many parts of the game that I need assistance with, I have been able to create different screens, as well as implementing the enemies, and score.
My next goal is to get gravity working.
